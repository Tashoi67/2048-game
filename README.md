# 🎮 2048 Game — сайт-игра на Laravel

Учебный проект: сайт с красивым оформлением, регистрацией/входом, игрой **2048** (не змейка!) и таблицей рекордов. Есть две роли — **Участник** и **Администратор** с отдельной админ-панелью.

## Что умеет сайт

| Страница | Кто видит | Что делает |
|---|---|---|
| `/` Главная | все | описание игры, топ-5 игроков, кнопка «Играть» |
| `/register` Регистрация | все | создание аккаунта (логин + пароль) |
| `/login` Вход | все | вход по логину и паролю |
| `/game` Игра | вошедшие | сама игра 2048: стрелки или свайпы, счёт, рекорд |
| `/score` (POST) | вошедшие | сюда JS отправляет результат раунда — он сохраняется в БД |
| `/leaderboard` Рекорды | все | топ-15 игроков: очки, максимальная плитка, дата |
| `/admin` Админ-панель | только админы | статистика, список пользователей, смена роли, удаление |

Роли:
- **Участник** — регистрируется, играет, его рекорды попадают в таблицу.
- **Администратор** — дополнительно видит админ-панель: статистику (пользователи/игры/лучший счёт), может сделать любого участника админом или наоборот, удалить пользователя (вместе с его рекордами).

Стандартный аккаунт админа создаётся сидером:
- Логин: `admin`
- Пароль: `admin123`

## Как запустить у себя (VS Code)

1. **Установить** (если ещё нет): PHP 8.2+, Composer, PostgreSQL 18 (в него входит pgAdmin), Git, [VS Code](https://code.visualstudio.com).
2. **Скачать проект** и открыть папку в VS Code:
   ```bash
   git clone https://github.com/Tashoi67/2048-game.git
   cd 2048-game
   code .
   ```
3. **Установить зависимости** (терминал в VS Code, Ctrl+`):
   ```bash
   composer install
   ```
4. **Запусти `setup.bat`** (двойным кликом или командой `.\setup.bat` в терминале) и введи пароль от PostgreSQL. Скрипт **сам**:
   - создаст базу данных `game2048` (pgAdmin руками открывать не нужно);
   - создаст все таблицы (`php artisan migrate`);
   - создаст аккаунт администратора `admin` / `admin123`.
   Если скрипт спросит пароль не так, как в `.env` — поправь строку `DB_PASSWORD=` в файле `.env` и запусти снова.
5. **Запустить сайт**:
   ```bash
   php artisan serve
   ```
   Открыть в браузере: http://localhost:8000

### Ручной способ (если setup.bat не сработал)

1. База создаётся в pgAdmin: ПКМ по *Databases* → *Create* → имя `game2048`, либо командой `CREATE DATABASE game2048;`
2. В `.env` укажи подключение:
   ```env
   DB_CONNECTION=pgsql
   DB_HOST=127.0.0.1
   DB_PORT=5432
   DB_DATABASE=game2048
   DB_USERNAME=postgres
   DB_PASSWORD=твой_пароль_от_postgres
   ```
3. Затем:
   ```bash
   php artisan key:generate
   php artisan migrate --seed
   php artisan serve
   ```

## Как объяснить работу сайта (коротко)

1. **Маршруты** (`routes/web.php`) решают, какой адрес что открывает. Например `Route::get('/game', ...)` — страница игры, и она закрыта `middleware('auth')`: не вошедшего перебрасывает на вход.
2. **Контроллеры** (`app/Http/Controllers/`) — это «мозги»: принимают запрос, работают с базой через модели и отдают вид (страницу).
3. **Модели** (`app/Models/`) — одна таблица базы = один класс. `User` — таблица `users`, `Score` — таблица `scores`.
4. **Миграции** (`database/migrations/`) — файлы, которые создают таблицы в PostgreSQL командой `php artisan migrate`.
5. **Виды** (`resources/views/`) — HTML-страницы (Blade-шаблоны). Общая шапка — в `partials/layout.blade.php`, страницы её наследуют через `@extends`.
6. **Игра** — JavaScript на странице `/game`. Каждое движение: повернуть поле, сжать строки (соединить одинаковые плитки), добавить новую плитку 2/4, перерисовать. Когда ходов не осталось — JS отправляет POST на `/score`, и Laravel сохраняет рекорд в таблицу `scores`.
7. **Роли** — просто текст в поле `role` (`'Участник'` / `'Администратор'`). В `AdminController` в конструкторе проверка: если роль не админ — ошибка 403.
